# NumPy

A practical study of NumPy fundamentals for Machine Learning and
numerical computing.

## Why NumPy?

NumPy provides the numerical computing foundation used throughout
the machine learning stack. This phase focuses on understanding
arrays, shapes, indexing, vectorized operations, broadcasting,
and other core numerical concepts before moving into data analysis
and machine learning.
